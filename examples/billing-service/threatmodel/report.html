Billing service

Threat model report · generated 2026-11-22T05:37:55.236Z

Description
Customers view and pay invoices in a React SPA. An nginx gateway terminates TLS and proxies to a FastAPI service that stores invoices in Postgres, charges cards through Stripe and queues receipt jobs in Redis for a worker that emails receipts via SendGrid. Users authenticate with Auth0.
Assumptions
Derived from docker-compose.yml and source code. The backend network is internal-only (docker-compose.yml:31). Auth0, Stripe and SendGrid are trusted third parties outside our control.
External dependencies
Auth0 (identity), Stripe (payments), SendGrid (email)
